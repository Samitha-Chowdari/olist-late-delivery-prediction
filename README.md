# olist-late-delivery-prediction
This project's main goal is to predict late deliveries of orders which are likely to happen, this lies on expected delivery date shown to customer at the time of purchase and actual delivered date of order to customer.
Predicting whether an order is going to arrive after estimated date, using the information available at the time of purchase.
The model is trained with historical data of olist which contains - orders, order items, seller, geolocation, ..etc.
We are solving the issue of late deliveries of orders which helps us to improve customer satisfaction, faster processing..etc.
